# 🤖 AI Interview Question Generator

Generate personalized interview questions, model answers, and interview tips based on any job role and experience level using AI.

## 🚀 Overview

AI Interview Question Generator is a web application designed to help students, freshers, and job seekers prepare for interviews more effectively.

Users can enter a job role, select an experience level, and specify the number of questions they want. The application then generates customized interview questions along with model answers and helpful interview tips using AI.

This project demonstrates the practical application of Generative AI in interview preparation and career development.

---

## ✨ Features

* Generate role-specific interview questions
* AI-generated model answers
* Interview preparation tips
* Support for multiple experience levels
* Custom number of questions
* Fast AI-powered responses
* Clean and responsive user interface

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/Sulochana160406/ai-interview-question-generator.git
cd ai-interview-question-generator
```

### Install Dependencies

```bash
npm install
```

### Configure API Key

Create a file named `src/config.js` and add:

```javascript
export const GROQ_API_KEY = "YOUR_API_KEY";
```

### Run the Application

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```
